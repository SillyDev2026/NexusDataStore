# NexusDataStore v8.5.0 — Release validation

## Scope

- Session read safety: typed `Session:TryGet` with detached tables and nonthrowing error handling.
- WaitForSession: no forced 50 ms delay on zero timeout; handles invalid keys, departed players, and store closing.
- Open/save write retries: clear attempt-local errors, verify lost acknowledgements without stale transform errors.
- Mutation safety: clone failures become explicit errors.
- GetStatus: commit/save/heartbeat/release/autosave fields for diagnostics.
- Restart GUI: server-clock countdown, late-bound RemoteEvent, UI state and reduced-motion attributes.
- No codec or persisted-record changes: format 700, Compression 2.6.1.

## Automated checks

- `python3 tools/verify_release.py` checks static source compatibility and the new invariants.
- `python3 tools/run_behavioral_tests.py --luau <path-to-luau>` runs the portable session and compression behavioral suites.
- GitHub Actions compiles Luau sources and runs both gates for pull requests and main commits.

## Roblox Studio / live-server checks still required

1. Confirm existing v8.4.3 player data loads unchanged, saves, releases, and reopens.
2. Simulate session ownership contention and recover from a transient failed save acknowledgement.
3. Confirm `WaitForSession` is immediate with `timeout=0`, and stopped when a player leaves.
